# 姻缘测算 · 八字合婚 × 紫微斗数

纯前端、零构建的姻缘测算单页应用。确定性排盘 + 传统规则打分，可选接入任意 OpenAI 兼容大模型 API 生成解读报告。双击 `index.html` 即可使用，排盘完全离线。

## 功能

- **双人合婚**：输入双方生日时辰，按传统规则确定性打分（基础分 50 加减，满分 99）：
  - 生肖年支：六合 +25 / 三合 +20 / 六冲 −20 / 相刑 −15 / 相害 −10
  - 日主五行生克、日干五合 +15、日支（夫妻宫）合冲刑害、年柱纳音五行、桃花互见
  - 打分明细逐项可查，结果可复现
- **单人姻缘**：配偶星（男看财星 / 女看官星）、日支配偶宫解读、咸池桃花、红鸾天喜、紫微夫妻宫主星
- **AI 解读（可选）**：将排盘数据与打分明细交给大模型，流式输出解读报告；Prompt 严格要求模型不得编造干支与星曜数据

## 使用

1. 双击打开 `index.html`（或任意静态服务器托管）
2. 填写生日（公历）与时辰——时辰影响时柱与紫微命盘，尽量准确
3. AI 解读：在「API 设置」页填写 OpenAI 兼容接口的 Base URL、API Key、模型名（如 DeepSeek / 智谱 / Kimi / 本地 Ollama），配置保存在浏览器 localStorage，不上传任何服务器

## 技术栈

| 依赖 | 用途 |
|---|---|
| [lunar-javascript](https://github.com/6tail/lunar-javascript) | 八字排盘（四柱、纳音、生肖） |
| [iztro](https://github.com/SylarLong/iztro) | 紫微斗数排盘（夫妻宫星曜） |
| 原生 JS | 合婚规则引擎、UI、SSE 流式解析 |

两个引擎库已随仓库附带在 `lib/` 下，无需联网即可排盘。
